# TallyReel

The website and the downloads for [TallyReel](https://tallyreel.com) — an app that turns an idea
into a finished video on your own computer.

- **Get the app:** [tallyreel.com](https://tallyreel.com)
- **Installers:** on the [Releases](https://github.com/danishs360/tallyreel-downloads/releases) page
- **Update feed:** `/updates/latest.json`, signed, which is what installed copies check

The app's own source lives in a private repo. This one holds the site you're reading and the
files people download, so every link has an address that doesn't move.
